Remote sensing / Raster workflows · Penn MUSA 6950 · Academic project

Mapping Miami’s vegetation.

From NAIP imagery to a 10 m vegetation grid

My role
Windowed imagery processing, NDVI calculation, and aggregation
Tools
Python · Rasterio · NumPy · NDVI
Recorded outcome
Vegetation summaries for the available imagery footprint

The question

How can high-resolution aerial imagery be turned into a manageable vegetation summary? This workflow uses NAIP imagery to calculate a vegetation signal and aggregate it to a coarser grid.

The workflow

I processed imagery in windows, calculated native-resolution NDVI, and classified valid pixels as vegetation when NDVI exceeded 0.1. I then averaged valid classifications within 10 m cells, retaining the distinction between valid low values and missing observations.

Reading the map

The supplied imagery covers only part of Miami. The output shows vegetation patterns within that footprint; blank areas have no imagery coverage in this analysis. They should not be filled with zero or interpreted as places without vegetation.

What the result means

The threshold classifies a spectral signal rather than validated tree-canopy cover. Grass and other vegetation can contribute to the result. Accuracy would need to be assessed against reference observations before using the map as a canopy inventory.
