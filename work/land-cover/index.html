Remote sensing / Machine learning · Penn MUSA 6950 · Academic project

Recognizing land from above.

Classifying land cover with transfer learning

My role
Model comparison, training workflow, evaluation and interpretation
Tools
Python · PyTorch · ResNet50 · scikit-learn
Recorded outcome
98.198% test accuracy

The question

How can a model distinguish forests, cropland, residential areas, and other land-cover types from satellite images? I compared a custom residual CNN with an ImageNet-pretrained ResNet50 on EuroSAT, treating validation and test data as separate steps.

My contribution

I adapted the course workflow into a reproducible comparison: stratified data splits, training-only augmentation, a custom residual architecture, two-stage transfer learning, and class-level error analysis. The classifier head trained first with the backbone frozen; the final residual stage was then unfrozen for fine-tuning.

The workflow

The 27,000-image dataset was split into 18,900 training images, 4,050 validation images, and 4,050 test images. Training used AdamW, label smoothing, a learning-rate scheduler, and early stopping. The run used seed 42 and a Tesla T4 GPU.

What the run showed

The selected ResNet50 checkpoint recorded 98.247% validation accuracy versus 95.852% for the custom CNN. Held-out test accuracy was 98.198%, with a macro F1 score of 0.9812. AnnualCrop was confused with PermanentCrop in 11 test images; HerbaceousVegetation was confused with PermanentCrop in 7.

What the result means

Transfer learning performed better in this recorded experiment. This is an image-level random split, not a geographically independent test; the score does not establish accuracy in a new city or region. The notebook selects checkpoints by validation loss and compares models using their associated validation accuracy. The figures report the saved run, not a new training run.

Coursework adapted from supplied course materials. Results are taken from the saved notebook; the analysis was not rerun for this portfolio.
